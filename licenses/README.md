# License Text Provenance

The files in this directory are verbatim upstream license texts downloaded or
copied from the exact dependencies used by HWM. When a dependency version
changes, refresh its license text and the release inventory.

- `LGPL-3.0.txt`: GNU Project, https://www.gnu.org/licenses/lgpl-3.0.txt
- `GPL-3.0.txt`: GNU Project, https://www.gnu.org/licenses/gpl-3.0.txt
- `QtKeychain-BSD-3-Clause.txt`: QtKeychain 0.15.0 `COPYING`
- `Lucide-ISC.txt`: Lucide Icons ISC license, including the Feather-derived
  icon list and its MIT license notice
- `Android-OpenSSL-Apache-2.0.txt`: KDAB Android OpenSSL pinned commit `LICENSE`
- `OpenSSL-Apache-2.0.txt`: OpenSSL 3 license
- `Android-NDK-r27c-Sysroot-NOTICE.txt`: exact `NOTICE` file copied from the
  Android NDK 27.2.12479018 sysroot used for the release build
